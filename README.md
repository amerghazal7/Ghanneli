# Ghanneli (غنّيلي)

A personal learning project from June 2026. I used a concrete idea, personalised Arabic gift songs generated by AI ("ghanneli" means "sing for me"), to practise an agentic, spec-driven development workflow end to end: a written design, an implementation plan with gates, task-by-task execution with coding agents, and reviews.

**Status: prototype, not a product.** Nothing here is in service, no payments are live, and the code is not maintained for use. It stays public as a record of the workflow and the architecture decisions, with the same honest scope as the rest of my work.

## What is in the repository

- `app/` — a Next.js and TypeScript web application scaffold: the song-request flow, an orchestrator API, a credits model, Drizzle schema and migrations, workers, tests.
- `ai-backend/` — a FastAPI service around music-generation engines: an ACE-Step engine for a self-hosted GPU box, adapters for hosted models used for A/B comparison, and a Modal deployment; lyrics routed through a hosted language model with an Arabic songwriting prompt.
- `infra/` — Terraform and Ansible skeletons for a Google Cloud deployment.
- `docs/` — the design document, requirements, analytics notes and the plans written with the spec-driven workflow (`docs/superpowers/`).
- `brand/` — logo explorations.

The two halves talk over one stable boundary, the `MusicGenerationService` interface, so the application could run on managed cloud while the model side evolved on its own.

## What I took from it

- How far a spec → plan → tasks → review loop carries a solo builder, and where it breaks (the reports under `.superpowers/sdd/` are the unedited record).
- Drawing a service boundary early enough that two engines could be A/B-tested behind it without touching the app.
- Prompt craft for Arabic lyrics across dialects, and what hosted music and language models do and do not give you.

## Running it locally

See `docs/local-dev.md`. The example environment files use placeholder values only; the AI backend runs in a fake-engine mode without a GPU.
